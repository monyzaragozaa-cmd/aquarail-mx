# AquaRail MX — Phase 1

**Educational simulation, not official municipal information.**

## Run

```bash
npm install
npm run train
npm test
npm run typecheck
npm run dev
```

Open http://localhost:3000. Try `FUGA-DEMO-101`, `102`, `103`, `104`. All data are fictional. No login, database, tracking, keys, paid APIs, or external maps.

The ML model is a real fitted synthetic linear regression, not a validated municipal predictor. Its estimated 0–100 index is advisory only and cannot alter human-event statuses or dispatch.
